Kvaesitso Bridge adds a quiet, transparent text notification widget to stock Kvaesitso and other Android launchers. Requires Android 12 or newer.

- Tap a notification to open it, or use its small dismiss control when Android permits.
- Choose Full, App only or Hidden for each app. Background noise is filtered by default.
- Configure text sizes, line limits, spacing and light/dark text in the settings app.
- Notification content stays on-device in memory. No network permission, analytics, ads or history.

Install `kvaesitso-bridge-0.1.0.apk`, enable Notification Access, then add the widget through your launcher's widget picker. To receive updates, add `https://github.com/massiveadam/kvaesitso-bridge` in Obtainium.

If a debug APK is already installed, uninstall it once before installing this release. The production release has its own stable signing key. Later release updates preserve settings.

Build, 26 unit tests and Android lint passed locally. Widget interactions, lifecycle recovery and appearance were exercised on an Android 17 emulator. Physical Pixel 10 Pro and stock Kvaesitso placement still need hands-on validation. Launcher-cached widget images can refresh asynchronously after lock or permission changes.

The APK is signed with the certificate recorded in [release-signing-certificate.sha256](https://github.com/massiveadam/kvaesitso-bridge/blob/v0.1.0/docs/release-signing-certificate.sha256). `SHA256SUMS` verifies the downloaded file.
